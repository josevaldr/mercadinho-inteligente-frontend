# Mercadinho Inteligente — Frontend

## Como executar

1. Instale as dependências:
   ```bash
   npm install
   ```
2. Crie um arquivo `.env.local` na raiz do projeto e informe o endereço do backend:
   ```env
   EXPO_PUBLIC_API_URL=http://IP_DA_MAQUINA:3000/api
   ```
   Use o IP da máquina que está executando o backend. O celular e o computador devem estar na mesma rede Wi-Fi.
3. Inicie o aplicativo:
   ```bash
   npm start
   ```
4. Abra pelo Expo Go lendo o QR code exibido no terminal.

Backend: [mercadinho-inteligente](https://github.com/josevaldr/mercadinho-inteligente.git)
